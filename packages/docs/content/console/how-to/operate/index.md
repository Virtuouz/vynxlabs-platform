Guides for what is running in a workspace.

- [Find and stop runs](find-and-stop-runs): find a run by what it did and cancel one, several, the queued ones or those that never finish.
- [Run again](run-again): run a script or flow again with the same or other input, on another version, from its failed step, or later.
- [Publish an event by hand](publish-an-event): try what listens for an event.
- [Pause triggers](pause-triggers): stop one trigger, a workspace's triggers, or the instance's.
- [Approve or reject a decision](approve-and-reject): decide what a flow waits for.
- [Get told when a run fails](set-failure-alerts): choose a script or a connection for failure alerts.
