# Phase 30 M1: the shared renderer

Lane m1, branch `p30-m1`. Two commits: the golden test before the move, then the move.

## Built

- **Golden HTML first** (`packages/docs-site/src/golden.test.ts`, files in `packages/docs-site/golden/`). 17 pages drawn by the old renderer: home (with and without look), a page with every component the docs profile allows, feedback asked/said/preview, a folder index, glossary, nested base path, missing page, search (empty, hits, none, escaped), not found (with and without notice). Includes the "New in version" line. They passed unchanged after the move; only hashed asset names are normalised. `UPDATE_GOLDEN=1` rewrites them. Not in the fixture: `:product[]` and `::screenshot`, which the docs profile refuses.
- **`packages/docs-site`** (`@volvel/docs-site`): `src/css.ts` (`DOCS_CSS`), `src/script.ts` (`DOCS_SCRIPT`), `src/icons.ts`, `src/render.ts` (`docPage`, `homePage`, `searchPage`, `searchAnswer`, `notFoundPage`, `pageAt`, `pageMarkdown`, `SiteView`), `src/html.ts`, `src/assets.ts`.
- **`SiteView`** (`render.ts`, replaces `Drawn`): `title`, `set`, `base`, `platform`, `look {themeHref, logoHref, iconsHref}`, `profile`, `productName`, `resolve {asset, screenshot, field, term}`, `search {server | static index}`, `trailingSlash`, `notice`, `feedback`. `draw` no longer fixes `profile: "docs"`. `trailingSlash` ends page addresses with a slash (not `_search`, not `.md`); `search.kind: "static"` is carried into `#docs-data` for M11; left out, output is byte-identical.
- **Hashed assets** (`assets.ts`): pages link `/_platform/docs.<10 hex>.css|js`. `front.ts` serves a name whose hash matches as `immutable, max-age=31536000`, a wrong hash as 404, and the old `docs.css|js` as before (`max-age=3600`).
- **Control plane keeps** the cache (`kernel/apps/docs.ts`: `docsOf`, `docsKept`, `DOCS_POLICY`), access, feedback, hosts. `front.ts` builds a `SiteView` in `serveDocs` and `serveDraftDocs` and calls the package.
- **Wiring:** root `tsconfig.json`, control-plane `package.json` and `tsconfig.json`, `Dockerfile` COPY, `scripts/release-check.mjs`, `scripts/release-version.mjs` (+ its test), `release.yml` publish loop, `pnpm-lock.yaml`, `biome.json` (ignores `**/golden`).
- **`private`:** the package is published as `@volvel/docs-site` (no `private`, `publishConfig.access: public`, Apache-2.0, version in step 0.5.0), as docs-engine is, because M11's static export and the website repository consume it.

## Spike: `describeApi()` without Postgres: YES

Prototype kept, small: `describeApi()` in `apps/control-plane/src/app.ts` (exported for generators as `describeApi(version?, config?)` from `@volvel/control-plane/testing`), test `apps/control-plane/src/describe-api.test.ts`.
- `buildApp` over a `Database` that is never connected works, and `app.swagger()` gives all 312 paths.
- Blockers found and removed: (1) `GET /api/v1/openapi.json` goes through the front-door hook (`hosts.place`), which queries; so the function calls `describe()` directly (`app.describeApi`). (2) better-auth's `generateOpenAPISchema()` connects to the database on first use; with `describing` set, `createAuth` gives it `memoryAdapter({})` (`kernel/auth.ts`, `kernel/kernel.ts`). Nothing else touched the database.
- M9: change `packages/docs/generators/api.mjs` from `startTestApp` to `describeApi`, so the API pages need not be committed. Needs `pnpm build` of control-plane first, as today.
