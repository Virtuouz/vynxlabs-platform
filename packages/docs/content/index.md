:product[] is one place to build internal apps, workflows and integrations, and to run them. This help follows the console: each screen has a page, and the page opens beside the screen with :kbd[F1].

- [Start here](start/index) for the ideas everything else uses.
- [Console](console/index): what each screen of the console shows and does.
- [Develop](develop/index): writing widgets, and the kinds, API and command line drawn from the code itself.
- [Administer](administer/index): people, access and delivery for a tenant.
- [Self-host](self-host/index): for whoever operates the installation.
