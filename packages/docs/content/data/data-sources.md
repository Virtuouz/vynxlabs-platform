Databases outside the product that a workspace reads as if their tables were its own.

## Browsing a source's tables

A data source's page fills the window, as a table's does. Its tables are listed beside the rows and scroll on their own; the rows are the one thing that scrolls on the other side, with the headers pinned. A reference column in a source's rows is named as it is in a table, by `name`, `title` or the first text column.

## Changing a source

**Change** on a connected source edits how it is reached from what it is now: the host, the database, the user. The password stays as it is unless you type a new one.
