# Phase 33, lane d4: the walk's six faults, and the writer's six more

## What changed
1. Heading levels, one rule: the page's own title is h1 and the highest level the author used is h2, the next h3, and so on. New option `headingTop` (`packages/markup/src/render.ts`: `shiftFor`, `context(options, tree)`; used by `renderHtml`/`renderReact`), which replaces the fixed `headingShift` on every surface: served product, tenant sites and the export (`packages/docs-site/src/render.ts` `draw`, `headingTop: 2`), the console Docs viewer and editor preview (`Docs.tsx`, `DocEditor.tsx`, 2), `MarkdownEditor.tsx` (2), and, where a title of the surface sits above the text, h3: help panel, `ErrorMeans`, `KitSheet`, `packages/ui/src/MarkdownBody.tsx` (3). A level can now be pushed up as well as down (the generated flow reference, written from `####`, is h2). "On this page" (`headingsOf`) lists the top level used and two below it (`data-level` 1 to 3), so on /docs it is three levels (7).
2. Prose size: `--body: clamp(16px, 14.4px + 0.45vw, 20px)` and the page widths in px (`packages/docs-site/src/css.ts`): a tenant theme's larger root no longer enlarges it. Measured with the root forced to 18.4px: 20px at 1440.
3. A changelog folder's pages run newest first in the navigation and in Previous/Next unless its index lists them (`packages/docs-engine/src/set.ts` `itemsOf`, with `newestFirst` shared with `changelogOf` in `changelog.ts`).
4. A version with no date no longer says "not released yet" (`packages/docs/generators/changelog.mjs`): only the Unreleased entry does.
5, 6. Page details (`apps/console/src/screens/docs/PageDetails.tsx`): Date is as wide as its column (no `max-w`), beside Description; the place note is a labelled line under the fields ("Place among the others.").
8. `::changelog` is in the Insert menu (`kit/markdown/insert.ts`; the existing test was failing for it). `::glossary` and `::pages` are there.
9. `volvel dev` serves `/changelog.xml` (`packages/cli/src/dev-site.ts`).
10. A `changelog/` folder with no index page is drawn as the list of its entries, as `::changelog` draws them (`docs-site` `pageAt`/`changelogIndexOf`; not a page of the set, nothing written). Served product, tenant sites, `volvel dev` all go through `pageAt`; the static export writes it too, and a drawn folder page has no "Copy as Markdown" (it has no source); the export crawl seeds `changelog/`.
11. The editor preview's `::changelog` lists the entries of the page's top folder when no app names it yet (`screens/docs/model.ts` `changelogFor`).
12. The CLI's older-instance advice names `date` (`cli.ts`); the pattern already had it.
