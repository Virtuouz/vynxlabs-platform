Where a script is written and tried, with the SDK's types to hand and a run of the draft one key away.

## What is saved is what you typed

:kbd[⌘S] pressed right after typing saves the text as it is now, not as it was a moment ago. Text typed while a save is on its way is saved after it. The flow editor, the resource editor, the page editor and the query editor save the same way.
