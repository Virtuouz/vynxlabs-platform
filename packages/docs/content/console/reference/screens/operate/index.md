What is running, what ran, and what changes next.

- [Runs](runs): The list of every run of a script or a flow, its filters, batch actions and inspector.
- [The run page](run-page): One run, its attempts, log, failure, diagnosis and comparison with the last success.
- [Events](events): The log of events published in the workspace, what each one started, and Publish an event.
- [Triggers](triggers): What starts work without a person: schedules, webhooks, events and forms, how each is paused, fired and refused.
- [Approvals](approvals): Flows waiting for someone to say yes or no, who may decide, and the page a mailed link opens.
- [Deploy and Versions](releases): Drafts to deploy, the versions a workspace has run, promotion to another workspace, requests and drift.
- [Git sync](git-sync): A dev workspace and a branch of the tenant's repository kept the same, and a production workspace's release branch.
