# Phase 34, lane b1: the widget kind and the author's SDK

## What changed
- `packages/widget-sdk/src/frame.ts` (new, entry point `@volvel/widgets/frame`): the frame protocol, the one module host and frame both import. `FRAME_PROTOCOL` ("volvel-widget/1"), `HostMessage` (`props`: `{config, data, state, size, theme}`), `FrameMessage` (`ready`, `event {event, payload}`, `size {height}`), guards `isHostMessage` / `isFrameMessage`, `MAX_FRAME_HEIGHT` 4000, `FrameTheme {scheme, tokens}`, `themeVariables()` (tokens as `--volvel-<token>`, plain values only). The host (B4) must check `event.source === iframe.contentWindow`, `isFrameMessage`, the declared event and the payload schema.
- `packages/widget-sdk/src/index.ts`: `EventDeclaration.payload?` (JSON Schema), `TENANT_PACK` ("x"), `tenantDefinitionProblems()`.
- `packages/manifest/src/kinds.ts`: `widgetKind` (type `x/<name>`, version, title, description, category, icon, surfaces, data, dataHints, config, words, defaults, events, layout, entry), `WIDGET_ENTRY_PATTERN`; registered before `interface`. `packages/manifest/src/widget.ts` `checkWidget` (contract's `definitionProblems`, namespace, path equals type, config and event payloads are JSON Schemas), called from `bundle-check.ts`. `registry.ts` `jsonSchemaProblem`. Deploy order: `widget` after `theme` in `cli/src/build.ts` and `control-plane/.../deploy.ts`. Schemas re-emitted.
- `packages/sdk/src/index.ts`: `defineWidget(options)` (shadows the contract's re-export; returns a resource at path = type, `.definition`), throws at define time. `WidgetOptions`, `WidgetResource`.
- `packages/cli/src/build.ts`: a widget's `entry` must be a file of the repository. `packages/cli/src/widget.ts` + `commands.ts` + `cli.ts`: `volvel widget new <name> [--dir]` writes `<entry dir>/widgets/<name>/{widget.ts,view.tsx,fixture.json}` and appends an export to the entry file.
- `packages/widget-frame` (new, `@volvel/widget-frame`): `createFrame({events})` -> `props()`, `onProps(cb)`, `emit(event, payload)` (throws for an undeclared event), `requestSize(h)`, `close()`; applies the theme as CSS variables, `data-theme` and `color-scheme`; hears only its parent; no network. `/react`: `useWidgetProps(frame)`. Added to Dockerfile, tsconfig.json, `scripts/release-check.mjs`, `release-version.mjs` (+test), `release.yml` publish list, lockfile.
- `packages/worker/src/define-parity.*`: widget entry. `packages/docs/src/sdk.test.ts`: the new entry point.

## Contract changes other lanes must know
- Host: import the protocol from `@volvel/widgets/frame`. The frame posts with target origin `*` (a sandboxed frame has an opaque origin); trust only `source`.
- `WidgetDefinition.events[].payload` is optional JSON Schema; the host (B4) checks it.
- The widget manifest's `path` is its `type`; body requires `layout` and `entry`, which the brief did not list.
- The bundle format is not changed; a built view (B2) is not made: `entry` is a source path.
