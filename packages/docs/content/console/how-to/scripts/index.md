Guides for the scripts of a workspace: trying a draft before it is deployed, running a deployed script now or later, giving one to an AI agent, and changing what a script runs with.

- [Test a script before you deploy it](test-a-script): run a draft on a worker, read its result and log, and find the line that failed.
- [Run a script now or later](run-a-script): start a deployed script with input, at a time and priority you choose, and run it again.
- [Offer a script to an agent](offer-a-script): let one service account start one script, and copy the address its agent connects to.
- [Change a script's settings](change-script-settings): change its limits, what it uses and what it does when it fails, and deploy the change.
