# Phase 30, M5: /docs and one /help handler

## Built
- `packages/docs-engine/src/package.ts` `openPackage(read)`: manifest read at once, a page's tree on first use (LRU of 64), search index on first search, `moved(address)` from the manifest's and `redirects.json`'s moves. Exported from the engine.
- `apps/control-plane/src/routes/product-docs.ts` (`productDocsRoutes`, registered in `app.ts` after the console's static files): `/docs` (308 to `/docs/`), `/docs/*`: pages, `_search`, `_search.json` (120 a minute per IP), `<page>.md`, `_theme.css`, `_theme.js`, `assets/*`. Public (`access.public`, hidden from the API description). Opened from `<consoleDir>/help`; none means 404. Drawn by `@volvel/docs-site` from a `SiteView` (product profile, base `/docs/`, `Volvel documentation` or the operator's product name, logo and icons from instance branding, instance version at the foot of the navigation, screenshots of the light look, `::field` from `fields.json`).
- Theme: `_theme.css` = `DEFAULT_THEME` merged with the operator's tokens (`themeCss`), so no console stylesheet is needed. `_theme.js` (a tiny file, CSP-safe) applies the console's stored light/dark choice (`vx-pref:theme`).
- Headers: `PRODUCT_DOCS_POLICY` (docs-site `policy.ts`: the docs policy without `https:` images, `frame-ancestors 'none'`), `X-Robots-Tag: noindex`, `nosniff`, `public, no-cache` + ETag over (build hash, version, branding revision, renderer hash, path+query); 304 on match; 300 rendered pages kept; `Link: rel=canonical` to `DOCS_URL` when set. Search results are `no-store`. Old addresses: 308 to the new page (`moved_from` and deleted pages).
- `/help/*`: ONE handler in `app.ts` (file in `kernel/docs/help-files.ts`), the static plugin gets `globIgnore: ["help/**"]`. Immutable only for `assets/screenshots/<name>.<12 hex>.png`; everything else `no-cache`; missing file or `..` is 404; the best of `.br`/`.gz` is sent. Phase 29's `isHelpFile` patch in the not-found handler is gone.
- docs-site (optional, absent = byte-identical): `SiteLook.scriptHref`, `SiteView.version` (foot of navigation, or the home page's footer), CSS `.side .version`.
- `packages/docs/build.mjs` + `load.mjs`: write `dist/md/<path>.md` (page sources, for Copy as Markdown).
- `apps/console/vite.config.ts`: dev proxies `/docs` and `/_platform`. (Dev serves `/docs` only if `apps/console/dist/help` exists.)
- `e2e/polish-setup.ts` `screens()`: `/docs/` added (a `main`, judged by the overdraw and nested-box measures). It is not a navigation section, so `NOT_MEASURED` does not apply.
