## Found (not mine to fix; for b4r or the lead)
- **A `rows` input of more than one page leaves the widget blank.** `TenantWidgetHost.tsx` `post()` sends `data` by `postMessage`; `RowsData.more` and `sortBy` are functions, which cannot be cloned, and the failure is swallowed ("Not cloneable: the frame keeps what it had"). Seen: a gauge whose `clinics` input read the appointments table drew nothing. The docs say so as a limit (what-a-view-is-given, widget-data-and-events): change them when it is fixed.
- The host always posts `state: ready`; `empty`, `failed` and `forbidden` are only seen in `volvel dev --widgets`. Said in the docs.
- Generated `@volvel/widget-frame` page: `FrameOptions.parent` shows its type as `Pick<Window` (the generator splits a type at its comma).
- `volvel deploy` to a workspace with console-made resources is refused until `volvel pull`; the how-to says so.
