# 11. Screen matrix

One row for every surface audited in [03-screen-by-screen-audit.md](03-screen-by-screen-audit.md): its current score, its main problems, the changes recommended, and what those changes wait on. Nothing here is implemented.

## How to read it

| Column | Meaning |
| --- | --- |
| ID | The screen ID from [01-current-product-ui-map.md](01-current-product-ui-map.md). Seven rows are not screens of their own and have no entry there: the four shared viewers (`UI-LOGVIEWER`, `UI-TIMELINE`, `UI-RESULTVIEW`, `UI-JSONVIEW`), the navigation model (`SH-NAV`), the expression field (`WS-EXPRESSION`) and the read-only flow graph (`WS-FLOW-GRAPH`). They were scored separately because several screens depend on them |
| Current score | Out of 100 on the rubric in 03. From code review and limited observation with mocked data, with a confidence of about ±5 points. A range means two reviewers scored the surface from different sides |
| Primary problems | The findings that cost users most. Evidence for each is in 03 |
| Recommended changes | What to do, in order of value |
| Priority | The highest priority level among the screen's fixes, then the main items from [09-prioritized-uiux-roadmap.md](09-prioritized-uiux-roadmap.md) |
| Effort | The screen's own work, not counting shared items it waits on. S: up to 2 days. M: up to 1 week. L: up to 3 weeks. XL: more |
| Dependencies | Shared roadmap items the screen waits on |
| Target score | A realistic score once the listed changes are made. It is an aim to test against, not a forecast |

## Summary

- **83 surfaces** are scored. The mean is **65.8**, the median 66, and the range 54 to 80.
- By band: 0 reference quality (90+), 1 strong professional (80–89), 23 good but visibly improvable (70–79), 47 functional / inconsistent (60–69), 12 major UX debt (under 60).
- The validation plan's targets are no surface under 70, and 85 or more for the high-frequency screens: the shell, the command palette, the workspace overview, the runs list, both run pages, the script editor and the flow editor.
