A script is a function the workspace runs: on a schedule, from a trigger, as a step of a flow, or by hand.

## Removing and creating

**Remove** is on the list's inspector and in the editor. It makes a draft that removes the script, and **Keep this script** takes it back before the draft is deployed. The same is true of flows, extensions, apps made in App Builder and queries. A script the repository manages is not offered for removal here, because the server would refuse it: change the repository.

**New script**, and the same for a flow, a resource, an app and a schedule, never replaces something. Asking for a path that a draft or a deployed resource already holds is refused on the path field, with what you typed kept.
