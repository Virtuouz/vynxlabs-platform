What is deployed, the drafts waiting to be, and the way to promote a dev workspace into production.

## Confirming a promotion

A promotion, and the review of a request to promote, share one confirmation. When the promotion would remove names that production uses, it says which and asks you to delete them anyway. A rollback in production is a danger confirmation that names the workspace.

## One list of deploys

**Versions of** the workspace is the one list of what ran here, newest first. Each version that is not the one running has **Activate this version**, which asks first: in production it is a danger confirmation that names the workspace. This is how a workspace goes back. Bundles that were uploaded and never activated here are in a small section under it, **Not yet run here**, with the same button.
