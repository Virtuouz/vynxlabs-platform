# Phase 33, lane d1: M1 type and headings, M2 anchors and contents, M3 theme switcher

## What changed
- Fluid type: `--body: clamp(1rem, 0.9rem + 0.45vw, 1.25rem)` on served sites (`packages/docs-site/src/css.ts`, `html`), `.vd-doc` at that size, line height 1.65, prose capped at 72ch. Title (2.4x), lead (1.15x), "On this page" (0.8125x, bar 0.875x) are steps of it. Measured: 16.2px at 390, 17.9px at 768, 20px at 1440 and 2560.
- Heading scale in `packages/markup/src/style.ts`: h2 2em with rule, h3 1.6em, h4 1.3em, h5 1.1em, h6 1em small caps; em-based, so the help panel and editor preview (`packages/ui` Doc) use it at their own size (16px base: h3 25.6px).
- Anchors: `withAnchors` and `themeControl` in `packages/docs-site/src/render.ts`; CSS reveal on hover/focus, always shown with no hover (touch); `DOCS_SCRIPT` (`script.ts`) copies on click via the `data-copy` loop and says "Link copied" in a `role=status` toast. Console `Doc` has none.
- "On this page": `headingsOf` takes `#` to `###`, `<li data-level>`, indent 14/26/38px, side and bar; `.now` text ignores the anchor's "#".
- Theme: `theme-script.ts` (blocking, first script of the head), served as hashed `docs-theme.<hash>.js` (`assets.ts`, kind `theme`; `DOCS_ASSET_PATH` shared by `front.ts`, `cli/dev-site.ts`); written by the export. `/docs` lost `_theme.js`; page data carries `themeKey: "vx-pref:theme"` for the product profile so the control reads/writes the console's key. Control (System/Light/Dark, hidden until script runs) in the phone topbar, home bar and at the foot of the side navigation.
