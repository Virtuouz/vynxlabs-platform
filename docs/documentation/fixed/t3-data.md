Test (seen failing before): `apps/console/src/Dashboards.test.tsx` "QSD-MP10: a table of a data source is offered as where a list reads from, and not to a figure". No migration, no API change.

- `kit/inspector/catalog.ts` `useSourceTables`: for each bound source, `GET data-source-tables/<path>`, named `<source>/<table>` as the server's `external` reader takes it; a table whose name is not a page path (a space, a capital) is left out; a source that cannot be read, or a reader without `data_source:read`, offers nothing. Used by `columnsOf`, the column pickers (`controls.tsx`), the page filters' columns (`filtersControl.tsx`), `defaultInputs`, `searchColumns`, `hasColumn`.
- Siblings looked at, not changed: `groupRowsControl.tsx` and `measureControls.tsx` read `catalog.tables` for groups and totals, which a source's table has none of; `tabProblems.ts` and `PublishCheck.tsx` already let a table with a slash pass; `column-values` and `column-counts` answer 404 for a source's table, which the editor already treats as "type it".
