A dev workspace and a branch of the tenant's repository, kept the same.

## One set of controls

Push and Pull are on this page alone. When a file has changed on both sides, you choose between the two versions side by side, one file at a time, and nothing is chosen for you. **Push** takes a commit message, with a default, and **Push with drafts** sends the drafts too. The panel beside a workspace's other screens only connects the branch ("Follow this branch") and says when there is no repository.
