# Phase 30 M1b: `volvel dev` for interface and docs apps (D64)

Lane m1b, branch `p30-m1b`.

## Built

- `packages/cli/src/dev-site.ts`: `siteApps` (interface and docs apps of the repository, read from its manifests, so apps written as files in `platform/` count), `startSiteServer`. A plain Node server:
  - interface: the runtime's `index.html` from `SCREENS_DIR` (else `packages/screens/runtime/dist` beside the build) with `vx-context` and the theme injected as `injectContext` does; its files; any other address is the page. `GET .../interfaces/<path>` is answered with the interface's body from the file, and the instance's `tables` and `groupNames` for the deployed one, kept when there is one.
  - docs: `docPage`, `searchPage`, `searchAnswer`, `pageMarkdown`, `notFoundPage`, the hashed `/_platform/docs.*` files and the pictures beside the pages, all from `@volvel/docs-site` and `buildApp` of docs-engine. A notice across the top says what is not drawn (product terms, readers' answers, diagrams).
  - the strict policy: `appPolicy()` for interfaces, `DOCS_POLICY` for docs; `--no-strict` leaves it off. `/api` goes to the instance with the developer's key, `/portal` as before. Reload by a server-sent event, from a script served by the server (the policy allows no inline script); files watched with `fs.watch`, a build that fails is shown on the page and recovers.
- `packages/cli/src/dev.ts`: lists apps of every kind; `volvel dev <app>` by path, no name with one app; an unknown app is refused naming the apps and their kinds. `tenantHasLogo` shared by both paths. The port is the next free one, as Vite's.
- `packages/cli/src/build.ts`: `BuildOptions.withoutAppSources` reads manifests and pictures without building apps with Vite.
- Shared piece moved: `DOCS_POLICY` now in `packages/docs-site/src/policy.ts` (exported), re-exported by `apps/control-plane/src/kernel/apps/docs.ts` so `front.ts` is unchanged. docs-site internals untouched otherwise.
- `packages/cli/src/commands.ts` help; `docs/sdk-guide.md` (new paragraph under "An app serves a folder"; there was no `volvel dev` line on interfaces or docs); wiring `packages/cli/package.json`, `tsconfig.json`, `pnpm-lock.yaml` (docs-site as a bundled devDependency); `node bundle.mjs` still builds.
