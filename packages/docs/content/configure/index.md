What the workspace's code needs to reach the outside.

- [Connections](connections): A connection is a connector with its settings and credentials filled in: one account at one system.
- [Variables](variables): Named values a workspace's scripts and flows read, different in each workspace.
- [Secrets](secrets): Values kept encrypted, written once and never shown again.
- [Alerts](alerts): Who is told, and how, when a run fails or a queue backs up.
- [Workspace settings](settings): The workspace's name, its limits, and how to clone or delete it.
