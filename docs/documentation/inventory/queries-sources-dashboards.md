## C. Gotchas
- Same-named columns are **kept**, in order; a whole number over 2^53 comes back as text; a zero-row result still has its column names (qry/run.ts:63-100, DAT-22). (This replaces the old "collapse" gotcha.)
- "Two people, different numbers" is intentional: policies apply as viewer, including saved queries and shared dashboards.
- A widget with a saved query now checks the query's parameters: needed ones, types, unknown names (qry/parameters.ts, DAT-17). SQL written in a widget has no typed parameters.
- A deploy of a dashboard fails on an unfinished widget or unknown table; a member's dashboard saves with them and says what it reads that the workspace lacks (`problems`).
- Opening an app's page refuses SQL sources.
- A widget may read `<source path>/<table>` (list/table only, no totals, joins or policies); the console now offers it (QSD-MP10). A source's table with a name that is not a page path (a space, a capital) is left out of the picker.
- "Rows behind" works only for table sources, not saved query/SQL.
- Last-N ranges include today; the day is the reader's zone on a page, UTC in SQL and `queries/visual`.
- Only a dev workspace keeps queries; production gets them by promotion and runs them by name.
