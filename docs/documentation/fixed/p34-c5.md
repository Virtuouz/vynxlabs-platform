# p34-c5: the help panel animates like the other panels

Owner: "The side menu for documentation within the console should animate similar to all other drawers."

## What changed
- `apps/console/src/help/HelpDock.tsx`: the panel is wrapped in the shared `Appear` (`packages/ui/src/presence.tsx`), as the shell's flyout is, with the shared `transition-[opacity,translate] motion-slow` and the `data-[starting-style]`/`data-[ending-style]` classes (fade, 24px slide from the right edge). It is no longer removed in one frame. `Appear` supplies the 280 ms stay, `inert` while leaving, and the reduced-motion path (none, removed at once); the stylesheet's own reduced-motion rule also stops the transition. No timing was copied.
- Focus: the "give focus back" effect now also runs when focus is still inside the leaving panel (before it is inert), so it returns to the opener. Escape still closes from inside; focus still moves to the heading on open.
- The positioning classes and `data-help-panel` moved: positioning is on the `Appear` wrapper, `data-help-panel` stays on the `aside`.

## Tests
`apps/console/src/help/Help.test.tsx` (67 pass): new "arrives and leaves with the motion the other panels have" and "with reduced motion it goes at once"; Escape tests wait for the leave. Console typecheck clean.

## Looked at
Throwaway instance (port 4365, db c534, admin sign-in, no Fernhill needed): 1440 (docked), 768 (over), 390 (full), light and dark, normal and reduced motion emulated. Opacity/translate sampled every 40 ms on open and close: eased 0 to 1 and 24px to 0, reverse on close, inert while leaving, none under reduced motion. Keyboard: Enter on the help button opens, focus in the panel, Escape closes and focus returns to the button. Reload: the panel does not reopen. No console errors.

## Not changed
The published docs site (`packages/docs-site`) is not the console; its nav already has its own transition (css.ts:78). `Docs.tsx` is the authoring screen and has no drawer.
