# Phase 30, M3: the Diátaxis engine

## Built

- Frontmatter `type`, `subjects` (schema allows 20, 5 count, more is a warning), `moved_from`: `packages/docs-engine/src/schema.ts:150-180`. `type` has no enum in the schema so that an unknown type is a warning, not a refused deploy.
- `diataxis.ts` (new): `DOC_TYPES`, `effectiveType` (own type, else nearest folder index, an index has none), `diataxisIssues` (warnings: `type_unknown`, `subjects_many`, `subject_once`, `type_folder`, `type_steps_missing`, `type_steps_present`, `type_title`, `type_goal_missing`), `DOC_TEMPLATES`. "Goal heading" is read as: a how-to has at least one heading; "steps" is a numbered list or `:::steps`.
- `set.ts`: `DocSet.types/subjects/redirects`, `PageRef.docType` (named so, `type` is the page/folder tag), `moved_from` errors (`moved_from_self`, `_exists`, `_duplicate`), `relatedTo` (shared subjects or `about`, 4 per type, same collection, nav order).
- `among.ts`: `PageIndex.type/subjects/moved_from`; the editor checks moved_from and the page's own lints. Subject-once and folder-untyped need the whole set and are said by a deploy only.
- `ops.ts`: `newPageSource(title, type?, inherited?)`, `planNewPage({type})` (no `type:` written when the folder says it).
- `output.ts`: manifest pages carry `docType`/`subjects`, manifest `redirects` (only when present).
- `search.ts`: `docType` stored, not indexed; `type` filter on `search` and `grouped`; `PageHit.docType`. m2 not merged at the time: this is the minimal field.
- `docs-site`: eyebrow, type cards on a collection's index (two or more types), Related block, type chips in the search dialog (`data.types`), `css.ts`. control-plane `front.ts`: `type=` on `_search` and `_search.json` (two sites each).
- CLI: `Built.warnings` (from `workspaceDocsWarnings`) printed to stderr by `build` and `deploy`; `refusal` adds "the instance may be older" when the refusal names `type`, `subjects` or `moved_from` as unknown.
- `packages/docs/check.mjs` + `lint-allow.json`: allow list that only shrinks (stale entry fails). Warnings already fail the product check.
