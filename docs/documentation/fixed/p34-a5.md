# Phase 34, A5: defaults move to YAML

## What changed
- `packages/cli/src/local.ts` (`STARTER`, `init`): `volvel init` writes `volvel.yaml` (`entry: scripts/hello.ts`, `resources: resources`), `resources/greetings.table.yaml`, `resources/hello-every-morning.schedule.yaml`, `scripts/hello.ts` (`tables: ["greetings"]`, `ctx.table("greetings")`, typed by `.platform/volvel-env.d.ts` after a build), `tsconfig.json` including `["scripts", ".platform/*.d.ts"]`, `.gitignore` with `.platform/`, and `.vscode/settings.json` through `writeEditorSchemas`. The script does not touch the table when the trigger is `local`, so `volvel run hello` (quickstart step 6) still works on a machine; in a workspace it keeps a row.
- `packages/sdk/src/context.ts`, `index.ts`: `Row<"path">`, `Insert<"path">`, `TableOf<"path">` (the last is what an app's `table<...>(path)` takes where it took `typeof definition`).
- `packages/cli/src/convert.ts` (`dropSpecifiers.used`): a name read as a member (`x.pets`) or an object key (`{ pets: 1 }`) is no longer a use, so the import goes. Convert refused Fernhill's scripts without it.
- Examples: acme and Fernhill converted (`volvel convert`, then by hand: `typeof x`/`x.__row` to the generated types, `Order` payload and `AGENT`/`FRONT_DESK`/`CLINICS` written out, concatenated CEL strings joined, flow steps naming scripts by path). `examples/fernhill/src/flows.ts` is gone. READMEs say what stays code and why (acme's is new); higher-ed-devices gets "Why this example is in code". Bundles are equal to the old ones apart from ownership (checked by building HEAD and now).
- Root `package.json`: `typecheck` runs `volvel types` for acme and Fernhill first (the file is not in git).
