:product[] is one place to build internal apps, workflows and integrations, and to run them. This help follows the console: each screen has a page, and the page opens beside the screen with :kbd[F1].

- [Start here](start/index) for the ideas everything else uses.
- [Build](build/index) scripts, flows and apps.
- [Operate](operate/index) what is running.
- [Data](data/index): tables, queries and dashboards.
- [Configure](configure/index) connections, variables and secrets.
- [Tenant](tenant/index): people, access and delivery.
- [Instance](instance/index): for whoever operates the installation.
- [Reference](reference/index): lists drawn from the code itself.
