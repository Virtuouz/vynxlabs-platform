How to tell the project about a suspected vulnerability, and where the policy lives.

## How to report

Report a suspected vulnerability privately, and not in a public issue, with GitHub's private vulnerability reports on the project's repository. There is no email address for security reports. A report is answered within 3 working days.

Say what you found, how to reproduce it, and which version you tested.

## What is covered

The newest minor version and the one before it get fixes for security problems. See [Versions, support and license](versions-and-support).

The policy, with what an instance protects and what it does not, is `SECURITY.md` in the repository. The same, in words for an operator, is in [What is protected, and a hardening checklist](../../explanation/running/security-hardening).

Related: [Versions, support and license](versions-and-support).
