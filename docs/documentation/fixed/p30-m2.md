# Phase 30, lane m2: gaps

## Built

- **Product profile allows `pages` and `glossary`**: `packages/markup/src/registry.ts` (both components now list `["product", "docs"]`). Images: the product profile already draws files beside the page through the `image` resolver; `https` pictures stay refused there on purpose (the design's CSP drops `https:` images and the pages must show offline). The gap the design means is the resolver, which M5/M7 supply.
- **Highlighting, classes only**: `RenderOptions.highlight` (`packages/markup/src/render.ts`, `codeBlock`), a dependency-free highlighter `packages/markup/src/highlight.ts` (`highlightCode`: js/jsx/ts/tsx, json, yaml, sh/bash, sql; anything else, and mermaid, unchanged), `hljs-*` classes. Colors: light in `DOC_CSS`, dark in `DOC_DARK_CSS` (`packages/markup/src/style.ts`), included in docs-site's CSS (`packages/docs-site/src/css.ts`) and in `Doc` (`packages/ui/src/Doc.tsx`). Served tenant sites pass it in `packages/docs-site/src/render.ts`. Every `Doc` caller (help panel, docs editor preview, Docs screen, MarkdownEditor/Body, KitSheet) gets it by default. No CSP change.
- **Search index without full text**: `packages/docs-engine/src/search.ts`. Pages index only their intro; sections index their words; only a clipped passage (400 characters, `PASSAGE_LENGTH`) is stored. `type` is stored, not indexed, empty (m3 fills it in `buildSearchIndex` and may add a `type` filter beside `collection`). Reference pages (a `reference` folder in the path, or stored type `reference`) score x0.6 unless the query equals the page's title or a heading in full. `search()` now rolls section hits up to pages, so a word deep in a section still finds its page. Old indexes (with `text`/`intro`) still load.
