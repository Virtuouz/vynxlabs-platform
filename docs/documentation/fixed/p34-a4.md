# Phase 34, A4: `volvel convert`

## What changed
- `packages/cli/src/convert.ts` (new): `convertRepository`, `describeConvert`, and a small scanner for TypeScript (`scan`, `statementsOf`, `notLiteral`, `linksOf`).
  - The files are written from the bundle's own manifests by `renderResourceFiles` (the writer Git sync uses), into the resources folder. The TypeScript is read only to decide what can be cut out whole.
  - The TypeScript compiler's syntax tree is not usable: the `typescript` package here is 7.0.2 (native), whose JavaScript API is unstable and runs a separate process, and the CLI is bundled with esbuild for publishing. The scanner replaces it. The rebuild-and-compare is what makes it safe.
  - Converts a top-level `export const x = defineY({...})` whose argument is literal; `column.*`, `z.*`, `step.*` and `trigger.*` calls with literal arguments are allowed.
  - Left, each with its reason: a script, connector, trigger source, widget, doc, or an app with `source`; a computed value (the identifier is named); a spread; a template with a part computed; a call; an export not written as `export const x = define…(…)`; a definition used again in its own file; a definition imported by another file (the message says to use `ctx.table("path")` and so on with the generated types).
  - Removes the leading comments directly above a converted export, and a comment after it on its line (counted and said). Takes `define*`, `column`, `z` out of imports that no longer use them. A file left empty is removed, with the `export *` that named it; the entry file is kept as `export {};`.
  - Resources folder: `volvel.yaml`'s `resources`, else the `--resources` flag, else `platform/` if the repository has one, else `volvel.yaml` is written with `resources: resources` and that is said. (The brief said always create it; with `platform/` present, as in Fernhill and higher-ed-devices, that would have moved the docs root and the existing files, so the existing folder is used.)
  - Writes everything, rebuilds, and compares every manifest (key, schemaVersion, title, body; not ownership) and checks the converted ones are `ui`. Any difference puts back the TypeScript and removes what it wrote. `--dry-run` prints the plan and writes nothing (it does not rebuild).
- `packages/cli/src/build.ts`: `authoredDefinitions(options)`, the definitions by export name (with `source` for an app). The stray doc comment above `readRepositoryConfig` went with the edit.
- `packages/cli/src/cli.ts`, `commands.ts`: the `convert [--dry-run] [--only <kind>,…]` command.
